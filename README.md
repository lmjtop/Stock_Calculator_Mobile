# Stock_Calculator_Mobile
Stock portfolio calculator for mobile

## 여러 기기에서 안전하게 사용하기

- 각 접속은 Supabase의 `updated_at` 값을 함께 불러옵니다.
- 저장은 ID와 기존 `updated_at`이 모두 일치하는 행만 원자적으로 변경합니다.
- 다른 기기에서 먼저 저장했다면 저장을 중단합니다. 화면의 입력값을 JSON으로 백업한 뒤 “최신 데이터 불러오기”를 누르세요.
- DB 조회 실패나 손상된 데이터가 발견되면 빈 포트폴리오로 대체하지 않고 실행을 중단합니다.
- 저장 실패 시 미저장 입력값을 유지하고 추가 저장을 차단합니다. 재조회 후 필요한 변경을 다시 입력하세요.
- 현재 화면 JSON 백업은 다운로드용입니다. 자동 이력 보관이나 JSON 가져오기 기능은 포함하지 않습니다.

## 적용 조건

기존 `stock_portfolio` 테이블의 `id`는 기본키 또는 고유키여야 합니다. `data`는 JSON/JSONB, `updated_at`은 timestamptz 형식을 사용하세요. 기존 테이블이 이 구조라면 추가 SQL은 필요 없습니다.
앱의 Supabase 키에는 해당 행의 SELECT, INSERT, UPDATE 권한이 필요합니다. UPDATE 결과 행을 읽을 수 있어야 저장 완료를 확인합니다. 키를 저장소에 올리지 마세요.

Streamlit Cloud에서 이 버전을 배포한 뒤 **모든 기기의 이전 탭을 닫고 다시 접속하세요**. 이전 버전으로 실행 중인 세션에는 보호 기능이 없습니다.

## 확인 절차

1. PC와 휴대폰에서 같은 데이터를 불러옵니다.
2. 휴대폰에서 수량을 변경하고 저장 완료 표시를 확인합니다.
3. 이전 PC 화면에서 값을 수정합니다. 저장 충돌이 표시되고 휴대폰 값은 유지되어야 합니다.
4. PC에서 백업 다운로드 후 최신 데이터를 불러오면 휴대폰 수정값이 표시되어야 합니다.
5. DB 연결 실패 시 빈 입력 화면으로 진행하지 않고 불러오기 오류를 표시해야 합니다.

Streamlit 휴면 기능은 유지됩니다. 휴면 후에도 입력 데이터는 Supabase에서 다시 불러옵니다.
